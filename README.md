# Сайт «Нскмастер» — ремонт коммерческой недвижимости, Новосибирск

Простой одностраничный лендинг без калькулятора. Статичные файлы: работает на любом хостинге
(GitHub Pages, Vercel, Timeweb, Beget), сервер и сборка не нужны.

Опубликован: https://ceomanagersites.github.io/nskmaster/ (репозиторий `ceomanagersites/nskmaster`, ветка `main`).

```
npx.cmd --yes serve@14.2.4 -l 5178 .
```

## Публикация

Изменения публикуются отправкой в GitHub (`git push`), GitHub Pages обновляет сайт примерно за минуту.

После правок `css/site.css` или `js/site.js` увеличьте номер `?v=5` → `?v=6` в ссылках на эти файлы в `index.html`.
Иначе браузеры посетителей до 10 минут показывают старую версию.

**Перед запуском на домене клиента** удалить строку `<meta name="robots" content="noindex, nofollow">`
в `index.html` и в `robots.txt` заменить `Disallow: /` на `Allow: /`.
