# Сайт «Нскмастер» — ремонт квартир и помещений, Новосибирск

Одностраничный сайт с обложкой и встроенным калькулятором сметы (основа — калькулятор `remont-smeta`
из папки «10. Ремонт квартир»). Статичные файлы: работает на любом хостинге (GitHub Pages, Vercel, Timeweb, Beget),
сервер и сборка не нужны.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Все тексты сайта: обложка, услуги, «ремонт ночью», этапы, отзывы, вопросы, контакты |
| `js/config.js` | **Цены калькулятора** и каналы заявки (Telegram, WhatsApp) |
| `js/calc.js` | Логика калькулятора (обычно не трогать) |
| `js/site.js` | Фасад дома с окнами на обложке, мобильное меню |
| `css/site.css` | Стиль «Ночная смена»: цвета в начале файла, блок `:root` |

## Как посмотреть

Открыть `index.html` в браузере или запустить локальный сервер:

```
npx.cmd --yes serve@14.2.4 -l 5178 .
```

## Публикация

GitHub Pages — загрузить содержимое папки в репозиторий и включить Pages. Vercel:

```
npx.cmd vercel@latest deploy --prod --yes --project nskmaster --create-if-missing
```

**Перед запуском на домене клиента** удалить строку `<meta name="robots" content="noindex, nofollow">`
в `index.html` (сейчас сайт закрыт от поисковиков как черновик).

## После правок

Если меняли `css/site.css` или файлы в `js/`, увеличьте номер `?v=2` → `?v=3` в ссылках на эти файлы в `index.html`.
Иначе браузеры посетителей до 10 минут показывают старую версию.
